# P3 挂锁 Android 修复与验收

日期：2026-09-16。版本：3.5.6（356），target SDK 36、最低 API 21。分支：`codex/padlock-acceptance-fixes`。

来源：[本次挂锁 Bug 清单](https://n0dycg1309.feishu.cn/wiki/PyhDwhUmQiNqIakAPa8c64Ftnhh?table=tblsFy4O3v1AR5ML&view=vew6I1X3bZ)。按用户要求，仅修改 Android；表中标记 iOS 的挂锁同类问题也核对并修复 Android 对应页面。iOS Wi-Fi 密码问题不属于本次范围。

## 2026-09-17 图片更新

按用户最新要求同步 iOS 提交 `a49586e` 的挂锁素材。首页、添加列表及全部引导页统一使用最新带左侧竖排 Logo 的 `padlock_outline`（837×1254）；详情页同步最新实物图 `product_padlock`（762×1254），两张均保留透明背景。旧独立无 Logo 列表资源已移除。此更新覆盖下文 9 月 16 日的图片规则；当日截图保留为历史记录，不代表本次新图。

本次为图片同步，原有功能修复保留。新安装包放在 `app/build/outputs/acceptance/2026-09-17/`，版本仍为 3.5.6（356）。

## 2026-09-17 恢复网关解锁

初次接入提交 `9e44c3c` 错误地将 P3 排除在网关解锁之外。按用户确认及 iOS 实现，移除详情页网关开关、远程开锁能力判断、设置页远程开锁入口三处 P3 专用限制，恢复原有 SDK 能力、网关关联及钥匙权限判断。自动闭锁和 App 主动闭锁仍不支持。本次国内 Debug、国内/海外 Release APK、海外 AAB 构建通过；实际网关解锁待真机验收。

包含网关修复的最新安装包位于 `app/build/outputs/acceptance/2026-09-17-gateway/`，版本仍为 3.5.6（356）。

## 2026-09-17 真机反馈调整

网关关联锁列表补齐 P3 型号判断，显示最新挂锁线稿，并按列表 40dp 高度等比缩放。P3 详情页在图片上方增加 32dp 间距，在电量与操作区之间增加 48dp 间距；其他型号保持原布局。

最终国内 Debug 构建通过，已覆盖安装到真机并成功启动，保留应用数据；位置与网关图标待用户目视验收。上述调整的安装包为 `app/build/outputs/apk/domestic/debug/app-domestic-debug.apk`，历史验收目录内的 Release 包尚未包含这两项界面调整。
